# Camera compatibility fixes — 2026-11-01

**Completed: the confirmed client-side fixes, scoped regression runs, release verification and disposable-client cleanup are recorded below. Known limitations and inconclusive cases remain explicit.**

Unlocked Camera remains **client-only: no server installation is required**. The fixes use client targeting and ordinary Minecraft rotation/use packets. They add no custom network channel, server payload handler, or server mixin. The release has 34 client mixins and no common/server mixin entries; its metadata permits connecting to servers without the camera mod. Actual integrated-server caller checks also confirmed that the local targeting overrides leave `ServerPlayer` rays unchanged. A dedicated-server login was not executed. [Release identity](../build/compat-fix-qa-2026-11-01/release-qa-identity.json), [client-only audit](../build/compat-fix-qa-2026-11-01/client-only-audit.txt), [current server-isolation results](../build/compat-fix-qa-2026-11-01/resync-release-regression/serverisolation-results.log).

The staged artifact is `build/libs/unlockedcamera-1.0.3.jar`, SHA-256 `07becc3d3b2fac3c6acad1ab5e3504ac7536a4bd0d74b68e80c4b3bbd0b61435`. It contains 52 production classes and no QA classes. All 52 release production classes match the final compiled QA runtime byte for byte. The large matrices below ran on the preserved `1efe9e8e…` release. Current-build follow-up results are recorded separately. No installation or commit is asserted by this report. These changes address four measured compatibility areas. They do not establish that every possible interaction, component variant, machine configuration, or addon workflow works. The earlier registry-wide results and their limitations remain in the [original test report](complete-registry-qa-2026-10-31.md); a separate [baseline snapshot](../build/compat-fix-qa-2026-11-01/baseline-report.md) preserves the pre-fix evidence.

The production fixes do not turn the local body or camera to make an action succeed. Camera rays exclude the camera-to-player gap and retain raw caller reach; world-space targets are checked against eye reach. Sable's own clipping and plot transforms remain in use. The AeroWorks pick-distance conversion accounts for rotation and scale before comparing distances in the caller's world-space metric. AeroWorks and Powergrid aim eligibility is main-hand only, matching the installed addons; an offhand module does not take over aim. Active ranged use retains its own aim priority.
